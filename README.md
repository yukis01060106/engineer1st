# エンジニア・ガレージ（ENGINEER GARAGE）

「フリーランスエンジニアの、ガレージ。」エンジンを整えて、仲間と走る。

フリーランス・SESエンジニアのための無料プラットフォーム（プロトタイプ）。
**部活・勉強会で集客し、無料ツールで毎月使ってもらいながら、見込み客をためていく**アプリです。

## デモ

**https://yukis01060106.github.io/engineer1st/**

インストール不要で、ブラウザで開くだけで触れます。

- 会員として: `tanaka@example.com` / `password123`
- 運営として: `admin@example.com` / `password123`
- 新規登録も試せます。操作した内容は、見ている人のブラウザにだけ保存されます（画面上部の「最初からやり直す」で初期化）
- デモ版ではサーバーを使わず、ブラウザの中のデモサーバー（`frontend/src/demo`）が答えます。請求書・スキルシートは「表示・印刷」からブラウザでPDF保存できます。サーバーでのPDF・Excel出力、レシートの読み取り、Claude版のAI FPは、実際のアプリでのみ動きます

デモを更新するときは `cd frontend && npm run deploy:demo`（ビルドして `gh-pages` ブランチに公開します）。
デモの初期データを更新するときは `cd backend && npm run seed && npm run export:demo` を実行して、`frontend/src/demo/seed.json` をコミットしてください。

## 構成

- `backend/` — Express + TypeScript + Prisma(SQLite)。ポート 4000
- `frontend/` — Next.js 16（App Router）。ポート 3001（3000 は別プロジェクトが使用中）
  - 請求・税金・資産形成などの計算は `backend/src/lib` が正本。デモ版でも使うため、build / dev の前に `frontend/src/shared` へ自動コピーされる
  - 公開ページ（`/` `/clubs` `/clubs/[slug]` `/events` `/events/[id]`）は SSG / ISR
  - ログイン後の画面は `(dashboard)` 配下の CSR

## 起動

```bash
# バックエンド
cd backend
npm install
npx prisma migrate dev   # DB作成・マイグレーション
npm run seed             # デモデータ投入（何度実行してもOK）
npm run dev              # http://localhost:4000

# フロントエンド
cd frontend
npm install
npm run dev -- -p 3001   # http://localhost:3001
```

フロントは `/api/*` を `BACKEND_ORIGIN`（既定 `http://localhost:4000`）へ転送します。

### AI FP を Claude で動かす（任意）

`backend/.env` に `ANTHROPIC_API_KEY` を設定すると、AI FP が Claude（`claude-opus-5`）で回答します。
未設定のときは、本人データを使ったルールベースの「簡易モード」で回答します。

## 機能

### 集客（PLG）
- **部活**: いまはピックルボール部・筋トレ部が活動中（ランニング・フットサル・ボルダリング・朝ストレッチは準備中＝入部・申込不可）。参加には無料登録が必要で、部活ページから登録するとそのまま入部
- **勉強会・イベント**: 参加フォーム（目的・経験レベル・事前質問）を送ると、その場で参加URLを発行。Googleカレンダー / .ics 登録
- **登録フロー**: 働き方（フリーランス / SES会社員 / 独立検討中）と関心を選ぶ3ステップ。流入元（どの部活から来たか）を記録
- **はじめの一歩**: 登録直後のホームに、働き方に合わせた最初の行動（部活に入る・取引先を登録する・備えプランをつくる…）をチェックリストで表示
- **招待リンク**: 部活・勉強会・ホームから友だちを誘える（`?ref=会員ID`）。紹介で登録した人数は運営画面で集計
- **運営画面** `/admin`: 相談・問い合わせ（返信待ちのチャットへの返信、メンター相談の状態の更新）。見込み客を「いま案件の提案を喜んでもらえそうか」でスコア化（契約終了間近・独立検討中・スキルシート作成済みなど）。勉強会の告知作成、申込者と回答の確認

### カレンダー・ToDo
- 自分の予定（時刻つき）とやること（期限つき・なしどちらも）を登録。ToDoは「期限切れ・今日・これから・日付なし」に分けて表示
- 申し込んだ勉強会・部活、請求の入金期日（期日超過も）、契約終了日は自動でカレンダーに入る
- ホームに「今日の予定・ToDo」を表示し、その場で完了にできる

### 事務と将来の備え
- **取引先の登録**: エンジニア・ガレージ以外で見つけた案件も自分で登録できる（案件一覧には公開しない）。契約終了日を入れると45日前からお知らせ
- **請求書**: 適格請求書の記載事項（発行者と登録番号・取引期間・取引内容・税率ごとの対価と消費税額・宛名）をそろえた体裁。PDF（日本語フォント埋め込み）と、ブラウザで印刷・PDF保存できる表示ページ
  - 精算: 上下割・中間割・精算なし、時間単価の端数（1・10・100円未満切り捨て）、稼働時間の単位（15・30・60分切り捨て）
  - 消費税は「1枚の請求書につき税率ごとに1回」端数処理（切り捨て）。源泉徴収は税抜額に10.21%（100万円超の部分は20.42%）
  - 発行前に請求書と同じ見た目でプレビュー。発行済みは取り消して発行し直せる（入金済みは不可）
  - 屋号・住所・振込先口座は設定画面で登録し、発行のたびに請求書へ写す（あとで設定を変えても過去の請求書は変わらない）。登録番号がなければ通常の請求書として発行
- **入金管理**: 支払期日を過ぎたら通知。フリーランス法（60日ルール）にもとづく催促文を自動作成
- **税金の取り分け**: 所得税・住民税・事業税・国保・年金・消費税（2割特例 → 2027・2028年分は3割特例）の目安と、入金から取り分ける割合
- **将来の備え・AI FP**: 生活防衛資金 → 小規模企業共済 → iDeCo → NISA の順で積立額を提案（会社員は年収から手取りを出し、共済は対象外・iDeCo上限2.3万円で計算）。契約単価・契約終了日・入金状況を前提に答えるAI FP（個別の金融商品は勧めない）
- **手取りシミュレーション**: SES会社員は、いまの年収と「独立した場合」を比較
- 経費（レシートOCR → 会計ソフト用CSV）。今月・今年の合計と科目ごとの内訳、月ごとの一覧

### からだ・仲間
- **健康**: 歩数・睡眠・運動・気分の記録（14日グラフ）、座りっぱなしリセットの3分ストレッチタイマー、健康診断リマインド
- メンター相談（テーマを選んで送信 → 進み具合を表示。運営が状態を「対応中・完了」に更新）
- 担当者チャット（内容に合わせた受付の自動応答 → 運営画面から担当者が返信。返信が届くとホームの「やること」に表示）

### 仕事
- 案件検索（働き方・単価で絞り込み、マッチ度順）と「話を聞きたい」（担当者チャットに届く）
- スキルシート: SES・フリーランス案件の紹介で一般的な型（イニシャル表記の基本情報、分類別のスキル要約と経験年数、資格、自己PR、職務経歴の表と担当工程の●）。Excel（A4横）と印刷用ページ
  - 経歴ごとに期間・業種・役割・人数・工程（要件定義〜運用・保守）・環境（言語／FW／DB／OS／クラウド／ツール）・概要・担当と成果
  - IT経験年数は経歴の期間から自動計算（重なる期間は1回だけ数える）。紹介に出せる状態かのチェックつき
  - 紹介文（サマリー）は要員紹介メールで一般的な【項目】形式で自動作成し、コピーしてそのまま送れる
- 単価・商流診断（スキルシートと稼働中の単価から自動入力、診断履歴）
- スキルギャップ（次に伸ばすと効くスキル3つと、学び方・関連する案件・勉強会）
- 契約書（契約条件の表・条項の全文・同意チェックと氏名一致で電子締結）

### アカウント
- 設定: 名前・働き方・インボイス登録番号の変更、パスワードの変更、ログアウト、退会（パスワードで確認し、データをすべて削除）
- SES会社員・独立検討中の人が請求・経費・契約の画面を開くと、フリーランス向けの機能であることを案内

### 公開ページ
- 利用規約 `/terms`・プライバシーポリシー `/privacy`（公開前に事業者情報に合わせて専門家の確認が必要）、404ページ

働き方によってメニューが切り替わります（SES会社員・独立検討中には請求・経費・契約を出さない）。

## 注意事項

- 税額・保険料・資産の試算はすべて概算モデルです。実際の金額は税理士・自治体にご確認ください
- インボイス登録番号・参加URLはダミー値です
- 案件レコメンドは簡易実装です（スキルシートと案件の必須スキルの一致率）
- パスワードを忘れたときの再設定（メール送信）はまだありません
